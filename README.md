# Lesorub Bot (Saw_Full)

Автоматический бот для работы **Лесоруб** на Arizona RP(G).

**Основной скрипт:** `Saw_Full.lua`

---

## ✨ Возможности

- **Полностью автоматическая рубка деревьев**
- Навигация по navmesh (с поддержкой готовых файлов)
- Автоматическая сдача дров
- Anti-admin система (обход проверок, уведомления в Telegram, звуковые оповещения)
- Авто-еда, анти-заморозка, анти-бот
- Настраиваемый радар
- Трейсеры, отладка, статистика
- Поддержка CJ-скина, бесконечного бега, ускорения анимации
- Умные паузы, прыжки, повороты (имитация человека)
- Telegram-уведомления о статусе и админах
- Сохранение прогресса (ежедневная/еженедельная статистика)

---

## 📁 Структура проекта

- `Saw_Full.lua` — главный скрипт
- `config.lua` — настройки и дефолтные значения
- `constants.lua` — координаты, точки сдачи, игнорируемые деревья
- `state.lua` — состояние бота
- `navmesh.zip` / `lesobot_libs.zip` — необходимые библиотеки и navmesh
- `lesorub_logo.png`, `icon.png` — иконки и логотип
- `version.json` — версия скрипта
